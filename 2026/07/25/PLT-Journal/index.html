我的培正喇沙挑战赛游记。

以下简称 PLT（培喇挑）。

NOI 前几天就要报名了。虽然 PLT 和 HKMO 集训队训练冲了，但是我还是打算参加 PLT。

之前打 ACM 有一个比较奇怪的经验，就是一个三人队不能全部都很强，不然会发挥失误（为什么呢）。我打的最好的几次，就是我自己一个人打，其次是我和 qwertim 带着黄元帅打下手。而打的最差一次就是和 Adam 和 ltw 两个 IOI 队成员，最后排 HKOI 倒数第一，太幽默了。

因此，Matthew 邀请 Andy 和我组队，真是正合我意。因为他们两个是学校里数学很好的，都是初中生。加上 Andy 经常会做我不会做的 ad-hoc，我和 Andy 在 HKOI 集训营里拿到了很逆天的团体成绩。学校里年长的几位我不敢带，因为如果我一直写代码感觉不是很好，并且优势并不互补。

于是，队就组好了，我们也成功成为 PCMS 正队。我们取名 Polynomial Laplace Transform，即多项式拉普拉斯变换。

我们的策略很简单。我全程打代码，然后负责所有算法题，他们两个负责 ad-hoc。

比赛

比赛开始前，Matthew 给我们介绍了今年 Fields 奖的研究内容，然后口糊了 2D Kakeya 猜想的证明方法（注：今年 Fields 奖是 3D），我听得津津有味。他还表示他学会了如何证明费马大定理，太强了。

比赛开始。在前一个小时里，我们切掉了 道签到题，感觉手感挺好。然后我看到 A 和 C 有很多人切，于是我让 Andy 想 A，我想 C。

我用了 分钟严肃思考出了 C，此时 Andy 对 A 也有想法。C 是可以直接枚举起点然后用 set 维护终点就行了。我先实现了 C，然后发现有一步假了，发现想复杂了，于是迅速改完切题。

Andy 给出了一个精妙的跳位解法，我感觉很神。我给出了一个贪心解法，然后我发现合并一下就对了。吃了发罚时就拿下了。

再看有人切的 J。我发现是哈希练习题，我先写了 map 做法，结果 TLE 了，于是严肃改为哈希。我先用单模哈希但 WA 了，改为双模又 WA 了，最后发现有一个地方改错了。改掉后 AC 了，但怎么吃了这么多罚时。

此时我打算做 F，因为是 shx 在 SMSOIer 里出的一道简单题的加强版。想了 分钟看到 Adam 切 F 了，确实是可做题。

我用了 分钟写代码，但因为是概率题不好调，所以又调了 分钟，感觉很劣。此时 Andy 和 Matthew 一起想出了 L 的解法，我很惊讶因为 L 没有人过。因此我为了保险起见继续写 F，结果交上去又 TLE 了。调了调根号分治的阀值，但还是 TLE。

然后我们发现我提交不了了，因为之前有一次提交一直在 Pending。此时距离比赛结束只有 分钟，感觉没救了。最后比赛结束了还在 Pending，真的没救了。

吗。

宣布考试延后十分钟，因为最后 分钟评测机很卡，但要求不能写新的代码。结果定睛一看，bsgm 那个 Pending 的提交过了！

有救了！

最后喜提 RK ，又是日常 ACM 发挥，拿到最多题数和最大罚时。上次哈工大深圳 ACM 也是这样。

刚好金奖，赢麻了。成为全场 MVP，写了 道题。事实上如果最后 F 没调这么久的话完全可以切掉 L，这样就 RK 了。不过这是我的问题，因为我本来打代码就很慢。

喜提奖杯+奖牌各一个。大合影，找 Adam 玩，合唱 NOI 版奔跑吧少年和过桥，收拾，跑路了。

The End
