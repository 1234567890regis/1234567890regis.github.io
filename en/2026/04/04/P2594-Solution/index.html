Problem

ZJOI 2009 Coloring Game

General Idea: You can choose a coin that is facing tails up, then select a connected component such that all grid cells of this component are located to its top-left, and flip the entire connected component.

Conclusion: All coins are independent of each other, so the value of the game is simply the XOR sum of the values of each coin existing individually.

But why are the coins independent? At first glance, this seems highly counter-intuitive; when you operate on a coin, it affects (specifically, flips) other coins!

This is where one falls into the mental trap of the "flipping" operation. Let's examine another game:

General Idea: You can choose a coin that is facing tails up, then select a connected component such that all grid cells of this component are located to its top-left, and then place a new coin into all cells belonging to this connected component.

We can prove that:

  • In the second game, the coins are pairwise independent.

  • The first game is equivalent to the second game.

The first point is fairly obvious because operations certainly do not interfere with each other: specifically, if and are different coins (sub-games) on the current board, if you can operate on and then operate on , you can also operate on and then operate on , yielding the exact same result.

The second point is also quite obvious, why? Because "flipping" is essentially taking the number of coins XOR , whereas the second game adds to the cells in the connected component. The difference between them is always just a multiple of .

According to Property (see the Prerequisites section), since two identical coins must form a losing state, and according to Property , adding a losing state has absolutely no effect on the board state (or the value).

(Actually, this part is already very intuitive to grasp, but for the sake of rigor, the game theory definitions are laid out here anyway.)

Therefore, we can directly discuss the winning strategy of the second game. This only requires analyzing each coin individually to compute its value, and then XORing them together—job well done.
