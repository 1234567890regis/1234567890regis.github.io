A simple Dynamic Convex Hull template that could solve a lot of difficult problems.

Original: Chinese

Translation: Gemini

Took some insights from LineContainer implementation.

Here, the meaning of p is the -coordinate where the current line loses its maximum status (becomes suboptimal). The meaning of the cmp function is to update u->p and return whether v has become obsolete (i.e., popped out of the convex hull).

Key Points:

  1. Remember to handle the edge case where u.k == v.k. The behavior differs when maintaining an upper convex hull versus a lower convex hull.

  2. Remember to mark p as mutable, because multiset/set treats elements as const by default, making it impossible to update the value of p otherwise.

  3. Since multiset/set does not support random access queries, when querying , we cannot use ternary search. Instead, we should binary search the position of p using the container's built-in lower_bound() function.
