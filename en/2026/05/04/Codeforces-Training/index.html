Matrix Sorting

Nice problem! Sorting is successful if and only if adjacent rows satisfy a partial order, which actually yields only conditions, instead of the conditions I initially thought. For each condition, we notice that the last sorting operation that affects the partial order relation of these adjacent rows must place them in correct order—this is the sole requirement. That is, the last sorting operation affecting these two rows cannot be in reverse order. Therefore, extract all sorting operations that have no constraints, execute them, and continuously update the constraints. This resembles a topological sort and can be implemented using a queue.
